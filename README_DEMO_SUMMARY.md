# DriveMate Demo Summary

This is a short presentation-ready summary of the DriveMate project for a mentor or demo audience.

## Project purpose

DriveMate is a local driving school management system built to help manage:

- students
- instructors
- lesson bookings
- payments
- progress tracking
- reminders and notifications
- admin oversight

The application runs locally and does not depend on external cloud services.

## What the student can do

A student can:

- log in
- view their dashboard
- see progress and lesson stats
- book an available lesson slot
- pay for a package
- receive booking confirmations
- get smart lesson suggestions
- receive reminder notifications before lessons
- track lesson history and notes

The student flow is centered around learning, booking, and staying on track with their driving progress.

## What the instructor can do

An instructor can:

- log in with an instructor account
- create lesson availability
- view their schedule
- see which students booked lessons
- update student progress and notes
- communicate with students
- monitor lesson performance

The instructor flow is centered around teaching and scheduling.

## What the admin can do

An admin can:

- log in as the owner of the system
- manage users and roles
- review platform analytics
- monitor payments
- manage core school data
- oversee system operation

The admin flow is centered around control, visibility, and system management.

## Main technologies

### Frontend

- React

- Axios

### Backend

- Node.js
- Express.js
- Prisma ORM
- SQLite
- JWT
- bcryptjs

## Why this project is useful

This project demonstrates a full-stack web application that handles:

- authentication
- role-based access
- scheduling
- progress tracking
- payments
- notifications
- admin reporting

It is practical, local, and easy to demo because it does not require a hosted database or cloud deployment.

## Demo flow

1. Admin logs in
2. Instructor creates lesson slots
3. Student books a lesson
4. Student receives confirmation and reminders
5. Instructor updates progress
6. Admin reviews metrics and users

This shows the full flow of a mini driving school management system.
